# Product Count Analysis – Task 15

## Project Overview
This project analyses products by category using the Superstore dataset. The main objective is to count unique products in each category and identify the category with the highest product count.

## Tools Used
- Google Sheets
- Superstore Dataset

## Sheets Created
1. Raw Data
2. Working Sheet
3. Product Count Analysis

## Work Performed
- Copied the original dataset into a separate working sheet.
- Identified Category and Product Name columns.
- Counted unique product names under each category.
- Compared the product counts.
- Identified the category with the highest number of unique products.

## Formulas Used
- COUNTUNIQUE with FILTER – To count unique products belonging to each category.
- INDEX, MATCH and MAX – To identify the category with the highest product count.

## Top Category
Office Supplies is the top category with 1,058 unique products.

## Conclusion
This project helped me understand how to analyse product categories, count unique products and identify the largest category using Google Sheets formula.
